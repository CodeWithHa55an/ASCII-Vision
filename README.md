
# ASCII Vision

A real-time Computer Vision project built with **C++** and **OpenCV** that converts images, videos, and live webcam feeds into ASCII art.

This project is being developed from scratch while learning Computer Vision and modern C++ development practices. The goal is not only to create an ASCII camera but also to build a well-structured, production-style software project.
